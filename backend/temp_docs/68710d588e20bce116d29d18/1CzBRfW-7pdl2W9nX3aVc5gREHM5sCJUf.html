LangChain Testing Sample

This HTML document is designed for evaluating document loading and semantic retrieval in RAG pipelines.

Framework Info

LangChain allows LLMs to interact with external data. It supports document loaders, embeddings, and vector databases.

Technologies Mentioned

  • Pinecone Vector Store
  • RecursiveCharacterTextSplitter
  • sentence-transformers/all-MiniLM-L6-v2
  • LangChain's founder: Harrison Chase

Useful Parameters

Default chunk size is 500 characters with a 20-character overlap.
