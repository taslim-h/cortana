# LangChain RAG Evaluation Document

This document contains factual and structured data ideal for testing semantic chunking and retrieval.

## Project Overview

LangChain is a framework designed for building applications with language models. It enables Retrieval-Augmented Generation (RAG), allowing models to access external data sources.

## Key Features of LangChain

- Supports loaders for formats like PDF, HTML, Markdown, DOCX
- Integrates vector stores like Pinecone and FAISS
- Enables semantic chunking via RecursiveCharacterTextSplitter
- Works with embedding models like Hugging Face's `sentence-transformers/all-MiniLM-L6-v2`

## Example Fact Statements

- The `RecursiveCharacterTextSplitter` allows chunks of 500 characters with 20-character overlap.
- Pinecone supports metadata filtering for advanced vector search.
- The founder of LangChain is Harrison Chase.
